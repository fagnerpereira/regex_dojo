Array#map · Novato

Transformar com map

Usando Array#map, crie um novo array com cada elemento dobrado.
dado
arr = [1, 2, 3]
resultado esperado
[2, 4, 6]
map entrega cada elemento ao bloco e coleta os retornos num novo array — o original não muda. Esqueleto: arr.map { |n| … }
Correto! map devolve um novo array.
Seu código retornaria algo diferente de [2, 4, 6] — confira o bloco.
formas de resolver
arr.map { |x| x * 2 }
map entrega cada elemento ao bloco e coleta os retornos num novo array.
arr.collect { |x| x * 2 }
collect é sinônimo exato de map; a maioria do código Ruby usa map.
correção simulada no protótipo
